# JS Practice

Small practice project with basic HTML, CSS and JavaScript lesson files.

## Overview

This repository contains a simple front-end practice workspace used to learn and experiment with JavaScript and DOM manipulation. Open `index.html` in a browser to run the examples.

## Files

- `index.html` — demo page and entry point
- `css/styles.css` — styles for the demo
- `js/leson-1.js` — lesson 1 script (note: filename contains a typo)
- `js/lesson-2.js` — lesson 2 script
- `js/lesson-3.js` — lesson 3 script
- `js/lesson-4.js` — lesson 4 script

## Setup & Usage

No build step or package manager required. To view the project:

1. Open `index.html` in your browser (double-click or use your editor's Live Server).
2. Use the browser devtools console to view logs and debug.

Optional: run a simple HTTP server if you prefer (examples):

Windows PowerShell:

```
python -m http.server 8000
```

Or with Node.js installed:

```
npx http-server -p 8000
```

Then open http://localhost:8000 in your browser.
